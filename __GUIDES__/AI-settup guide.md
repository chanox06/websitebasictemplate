The website is built using WordPress Gutenberg.

Prefer working with Gutenberg-generated classes and semantic custom classes such as:

.wp-block-group
.wp-block-columns
.wp-block-column
.wp-block-image
.wp-block-cover
.wp-block-heading
.wp-block-buttons
.wp-block-button
.wp-block-list

However, do NOT rely excessively on long Gutenberg-generated selector chains.

Whenever necessary, ask me to add a meaningful custom class to a Gutenberg block.

For example:

earnest-services
earnest-service-card
earnest-placement-process
earnest-process-step
earnest-support-section
earnest-testimonials
earnest-contact-section

Then target those classes with CSS.

This is preferable to fragile selectors such as:

Avoid selectors based on:

- nth-child
- Gutenberg block IDs
- temporary WordPress-generated IDs
- DOM position
- unstable autogenerated classes

unless absolutely necessary.

# LARGE DESKTOP REQUIREMENT

Typography should not become excessively large merely because the viewport becomes wider.
